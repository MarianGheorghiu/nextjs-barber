# Cristi Barber Shop — interfața curentă

Referința aleasă este direcția dark cu lumină portocalie din exemplele furnizate de utilizator. Nu sunt amestecate suprafețe pastel violet, carduri roșii pe alb sau identitatea veche Atelier.

- Fundal aproape negru `#101012`, suprafețe dark glass și reflexii discrete.
- Accent portocaliu cald, folosit pentru selecții și acțiuni principale.
- Text alb și tonuri secundare cu contrast, DM Sans, corp de bază 16px.
- Nume: **Cristi Barber Shop**, frizer: **Cristi Epure**.
- Pe mobil serviciile sunt în prim-plan, în rânduri lizibile. Cardul mare de prezentare este ascuns dacă nu există o programare reală a utilizatorului local.
- Navigație unică jos pe mobil, fără hamburger. Meniu orizontal pe desktop.
- Sheet-uri native `<dialog>` ancorate jos, cu handle, animație de intrare, focus/keyboard gestionate de browser și buton de închidere.
- Select cu listă proprie ancorată sub câmp, scroll, selecție bifată și chevron la 20px în interior.
- Clientul își creează cont. Frizerul are intrare separată la `/frizer`. Fără selector public de rol.
- Zile de minimum 70px lățime, glisabile orizontal; săgeți de săptămână de 44px.
- Fără ratinguri inventate. Datele locale sunt de test și pot fi resetate prin ștergerea datelor browserului.
